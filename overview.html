快速使用

将整个目录上传到 Alpine Linux 机器，然后执行：
$ bash sing-box-gateway-deploy.sh

脚本自动完成：安装依赖 → 下载核心 → 安装模板 → 部署面板 → 创建服务 → 启动

命令行更新工具

$ bash sing-box-gateway-deploy.sh --update-core # 更新 sing-box 核心
$ bash sing-box-gateway-deploy.sh --update-panel # 更新管理面板
$ bash sing-box-gateway-deploy.sh --update-sub # 拉取并合并订阅
$ bash sing-box-gateway-deploy.sh --convert URL [模板] # 转换订阅为 sing-box JSON
$ bash sing-box-gateway-deploy.sh --uninstall # 交互式卸载
